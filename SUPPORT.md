# Support

Thanks for using Burnt Labs software. Here is where to go for help.

## Documentation

Start with [docs.burnt.com](https://docs.burnt.com) and the `README.md` of the
repository you are working with. Many repositories also carry `docs/` and an
`AGENTS.md` describing project layout and conventions.

## Questions and Community

- **Discord** — [discord.gg/burnt](https://discord.gg/burnt) is the fastest way
  to reach the team and other builders.
- **GitHub Issues** — for reproducible bugs and concrete feature requests, open
  an issue on the relevant repository.

Please use Discord rather than GitHub issues for open-ended questions, setup
help, and "how do I..." discussions. It keeps issue trackers focused on
actionable work and you will usually get an answer faster.

## Reporting Bugs

Open an issue on the repository where the bug occurs and use the bug report
form. Include the version, your environment, and the steps to reproduce — a
report we cannot reproduce is difficult to act on.

## Security Issues

**Do not open a public issue.** Email
[security@burnt.com](mailto:security@burnt.com) and see
[SECURITY.md](SECURITY.md) for the full disclosure process.
